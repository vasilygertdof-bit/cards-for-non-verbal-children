# Мои слова — расширенная библиотека иконок

В настройках взрослого при создании и редактировании карточки можно выбрать эмодзи, собственную картинку или готовую иконку. Библиотека содержит **121 новую тематическую иконку** и **18 прежних** для совместимости, все работают без интернета. Для поиска иконки используйте строку поиска и список, разбитый по категориям.

Существующие карточки, выбранные прежние иконки, фотографии и записи сохраняют совместимость. Выбор значков включается в резервную копию. РЖЯ не используется.

**Лицензия изображений.** 121 новая иконка использует Font Awesome Free (Solid), Font Awesome Free Icons License: CC BY 4.0. Автор: Fonticons, Inc. https://fontawesome.com/license/free. Текст лицензии: https://creativecommons.org/licenses/by/4.0/ . Иконки встроены локально, размер и формат SVG адаптированы для приложения. Сохраняйте информацию об авторстве при распространении.

Перед обновлением действующего PWA сделайте резервную копию. Распакуйте архив в корень сайта на Vercel. Проверен синтаксис JavaScript, но необходимо протестировать работу на реальном Android.
